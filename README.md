## 🚀 Featured Projects

### 1. MediBot — Securing the Digital Hospital Ecosystem

A hospital-management and security project concept focused on protecting sensitive medical information while supporting core hospital workflows.

**Problem it addresses:** Hospitals manage sensitive patient records, staff access, operational information, connected devices, and billing. Weak access controls or compromised devices can expose critical data.

**Security and system design goals**

- **Role-based access control (RBAC):** Separate access for Manager, Doctor, Nurse, and Patient roles.
- **Two-level data sensitivity:** Keep highly sensitive patient information within the hospital’s local network while allowing appropriately controlled access to lower-sensitivity operational information.
- **Approval workflow:** Route proposed changes to selected lower-sensitivity data through temporary storage and supervisor approval before updating the main record.
- **Integrity checks:** Use checksums to help detect unexpected changes to selected data.
- **IoT honeypot concept:** Monitor connected medical devices and use decoy devices with synthetic data to distract or study suspected intruders without exposing real devices.
- **Self-hosted infrastructure goal:** Keep hospital data and core services under the hospital’s own infrastructure and administration.
- **Billing workflow:** Include hospital billing as part of the wider management system.

**Project status:** Project developed as an academic system. Use the repository documentation to distinguish implemented features from planned or conceptual features.

### 2. Steganography and Cryptography Integrated File-Sharing System

A secure file-sharing project combining cryptography with image steganography to protect content during transfer.

**Core workflow and features**

- User registration and login with unique usernames.
- Online-user visibility and recipient-based file or message transfer.
- Recipient accept/reject workflow for transfer requests.
- ECC public/private key pairs for users.
- AES encryption for content protection.
- Pixel Value Differencing (PVD) steganography to conceal encrypted content within an image.
- Extraction and decryption on the receiving side.

**Security concepts demonstrated:** Confidentiality, public-key cryptography, symmetric encryption, steganography, user authentication, and controlled file transfer.
